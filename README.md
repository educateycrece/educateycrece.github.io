# Fundación Edúcate y Crece — sitio web

Sitio oficial de la Fundación Edúcate y Crece (La Paz, Bolivia), publicado con GitHub Pages.

## Cómo se edita

- Los textos de cada página están en `fuente/` (`cabecera.html` y `pie.html` son comunes a todas).
- Después de editar, se ejecuta `construir.ps1`, que genera las páginas finales (`index.html`, `nosotros.html`, etc.).
- Estilos: `assets/css/styles.css` · Fotos: `assets/img/` · Videos: `assets/video/`.
- Al subir los cambios a la rama `main`, la web se actualiza sola en uno o dos minutos.
